# Entscheidungen

Neue Einträge kommen unten dazu. Nichts wird gelöscht, auch nichts geändert —
wer später fragt „warum eigentlich?", findet hier die Antwort.

Format: `## [JJJJ-MM-TT] <Bereich> | <Titel>`, darunter ein bis drei Zeilen
Begründung.

## [2026-09-14] Werkzeug | Claude Code statt Chatfenster

Claude Code arbeitet im Projektordner und darf Dateien lesen und schreiben.
Das Chatfenster kann das nicht. Für ein Projekt, das aus Dateien besteht,
ist das der Unterschied zwischen Zuschauen und Arbeiten.

## [2026-09-14] Projekt | Ein Kanban-Board als Übungsstück

Spalten und Karten kennt jeder. Wer das Werkzeug lernen will, soll sich nicht
zusätzlich mit dem Gegenstand herumschlagen.
